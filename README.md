# vasyl-volyk — Resume & Job Search Repository

Personal repository for resume materials and job search workflow.

---

## Files

| File | Purpose |
|------|---------|
| `MASTER_RESUME.md` | Complete inventory of all experience, skills, and background. Source of truth — never sent anywhere as-is. |
| `master-resume-project-instructions.md` | Custom instructions to paste into the Claude Project's **Custom Instructions** field. Defines how Claude operates as a resume assistant (three modes: build/update master, tailor for a role, resolve skill gaps). |
| `claude_instructions.txt` | Instructions for Claude in Chrome to scrape job postings and produce a CSV file with the following schema: `id, title, companyName, location, postedAt, employmentType, seniorityLevel, salary, applicantsCount, link, companyWebsite, jobFunction, industries, descriptionText` |

---

## Workflow

```
Claude in Chrome (chrome_claude_code_instructions)
      │  scrapes job postings, outputs CSV
      ▼
CSV file of job postings
      │
      ▼
Claude Project (master-resume-custom-instructions)
      │  tailors MASTER_RESUME.md for each role
      ▼
Tailored resume (Markdown)
      │  downloaded locally, stored outside this repo
      ▼
Application
```

---

## What Is NOT Stored Here

- Tailored resumes — generated by Claude per role, downloaded locally, not committed to this repo.
- The CSV file of job postings — generated externally, not committed.

---

## Keeping the Master Resume in Sync

The `MASTER_RESUME.md` in this repo and the copy in Claude Project Knowledge are **not synced automatically**. After any update:

1. Commit the updated `MASTER_RESUME.md` to this repo.
2. Re-upload it to Claude Project Knowledge (replace the old version).

Skipping step 2 means Claude will tailor resumes against a stale copy.
